---
description: Refine a backlog ticket until it is ready for development — acceptance criteria, scope and risk labels, dependencies, splitting into sub-issues when it is too big.
argument-hint: <issue number>
---

Load the `scrumia-refine` skill and follow it.

$ARGUMENTS

The argument is the ticket to refine. If none was given, ask which one rather than picking for the human — refinement order is a priority call, and priority is theirs.

A ticket leaves refinement with acceptance criteria that can be checked, or it does not leave. "Ready for dev" without them means the gap surfaces at execution, where it costs the most.
