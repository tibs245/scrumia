📋 scrumia-github-project

Tickets, colonnes, branches et PRs — l'état du travail, hors du dépôt.

slot · tracker version · 0.4.0

Ce dont il est responsable

Possède toute la vie d'un ticket : l'affiner jusqu'à ce qu'il porte un critère vérifiable, l'exécuter dans son propre worktree, router sa revue, et rendre compte de l'état du projet. Selon l'ADR-0013, il possède aussi le cycle du code — branches, worktrees, pull requests — une portée plus large que son nom ne le laisse croire.

Ce qu'il refuse

L'état du projet n'atterrit jamais dans le dépôt : un hook PreToolUse bloque net les fichiers d'état. Il refuse aussi de fusionner à votre place — la validation finale revient à l'humain.

L'hypothèse qu'il fait

Présume un gh authentifié et un tableau GitHub Projects. Coûte une dépendance stricte à GitHub et rien du tout hors ligne.
