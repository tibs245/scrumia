🎨 scrumia-design

Identity, tokens and components in the repo — and the role that guards them.

slot · design version · 0.4.0

What it is responsible for

Owns what a user actually sees: the written identity, the token vocabulary, one directory per component, an audit that reports drift and mutedness on equal footing, and a sync that publishes a component to a Claude Design project one at a time. Ships the designer standing role — the only role contributed from outside the team slot.

What it refuses

A value the tokens do not carry is a finding, never an inlined exception. The remote project is a review surface, never the source of truth, and a wholesale replace is refused.

The assumption it makes

Assumes the design system belongs in the repo, where it is versioned alongside what consumes it. Costs discipline on every single value — and a role with no design system to guard would only be judging on taste.
