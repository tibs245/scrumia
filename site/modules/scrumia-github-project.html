📋 scrumia-github-project

Tickets, columns, branches and PRs — the state of the work, outside the repo.

slot · tracker version · 0.4.0

What it is responsible for

Owns the ticket's whole life: refining it until it carries a verifiable criterion, executing it in its own worktree, routing its review, and reporting where the project stands. Per ADR-0013 it also owns the code cycle — branches, worktrees, pull requests — a scope wider than its name suggests.

What it refuses

Project state never lands in the repo: a PreToolUse hook blocks stateful files outright. It also refuses to merge for you — final validation is the human's.

The assumption it makes

Assumes an authenticated gh and a GitHub Project board. Costs a hard dependency on GitHub and nothing at all offline.
