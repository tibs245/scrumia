🧭 scrumia-practice-solid

One named point of the implementation contract: which design principles.

slot · practices version · 0.4.0

What it is responsible for

Refines which principles apply and, more usefully, where each one stops. The five, each with its application limit, plus an audit that reports over-application on exactly the same footing as violation, and a refactor skill to close what it finds.

What it refuses

It refuses to treat a principle as universal, and it refuses to arbitrate a stack question that belongs to the implementation module.

The assumption it makes

Assumes a principle without a stated limit degrades into ceremony. Costs judgement calls the audit cannot settle on its own.
