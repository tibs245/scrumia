# Business rules — Run horizon

## Value

For the visitor reading the home page past the hero. It brings the product's
core pitch made visible in one glance: a single run of seven steps, three
carried by a human and four by an agent, so the human/agent split that
`dev-flow` describes in words is seen rather than only read. It matters
because this is the one section that shows the split rather than asserting
it — a visitor who never reads a sentence of `dev-flow` can still see the
shape of the work. Measured: not instrumented today — no scroll-depth or
time-on-section data is tracked for this part of the page.

Business parent: none beyond the epic — the section renders content that
belongs to `dev-flow`, but is not that feature's implementation.
